# Tasks

Задача отмечается выполненной после реализации и указанной проверки. Частично выполненные задачи сохраняют пустой checkbox; подробности — в [отчёте проверки](../../../../docs/verification.md). Требования: [PRD](../../../../prd.md), спецификации `vod-seek-controls` и `seek-settings`; технический подход: [design](design.md).

По решению пользователя от 2026-11-13 проверки реальной рекламы, физического колеса мыши и жестов тачпада пропущены в этом выпуске. Они не являются оставшимися обязательными проверками и не считаются пройденными; требования к поведению сохраняются. Остальные части задач остаются в силе.

## 1. Основа расширения и интеграция Twitch

- [x] 1.1 Подготовить структуру расширения Manifest V3 с минимальными разрешениями; проверить загрузку распакованного расширения в Chrome без ошибок manifest.
- [ ] 1.2 Проверить на реальном Twitch контейнер VOD, признаки активного стрима, клипа, рекламы и замены видео; зафиксировать найденные точки интеграции и примеры проверки в документации проекта.
- [x] 1.3 Реализовать адаптер поддерживаемого контекста и подключение/очистку при смене плеера; на стенде проверить VOD → VOD → стрим/клип → VOD без дублей и оставшихся обработчиков.

## 2. Настройки и редактор

- [x] 2.1 Реализовать модель независимых списков, значения по умолчанию, преобразование минут в секунды и валидацию; проверить 0/1/6/7 кнопок, пустые списки, положительные целые и невалидные интервалы, небезопасные числовые значения.
- [ ] 2.2 Реализовать локальное хранение и восстановление конфигурации; проверить сохранение после перезапуска, отсутствие обращения к Sync/внешним сервисам и безопасное поведение при повреждённых данных.
- [x] 2.3 Создать английскую страницу настроек и открытие по иконке расширения; вручную проверить независимое редактирование списков и добавление/удаление/перестановку мышью.
- [x] 2.4 Реализовать сохранение валидных изменений, ошибки полей и сброс обоих списков; проверить сохранность последнего рабочего значения при ошибке и восстановление четырёх исходных интервалов.
- [x] 2.5 Реализовать получение изменений в открытых VOD; проверить применение одной настройки и сброса одновременно в двух вкладках без перезагрузки.
- [x] 2.6 Описать настройку списков, локальность хранения и сброс в пользовательской инструкции на английском; сверить описание с готовым редактором.

## 3. Колонки и перемотка

- [x] 3.1 Реализовать независимые колонки, порядок, центрирование и подписи; проверить разные количества кнопок слева/справа, пустые направления и значения по умолчанию.
- [x] 3.2 Реализовать видимость при наведении, стиль и изоляцию событий; вручную проверить переход указателя с видео на кнопку и обратно, скрытие при уходе и работоспособность штатной панели Twitch.
- [x] 3.3 Реализовать вычисление цели и активацию перемотки; тестами проверить направления и ограничения у начала/конца, вручную — сохранение play/pause и отсутствие клика по видео.
- [x] 3.4 Реализовать размещение в обычном, театральном и полноэкранном режимах и при изменении размеров; проверить на реальном VOD, что кнопки остаются внутри плеера и не перекрывают нижнюю панель.
- [ ] 3.5 Реализовать внутреннюю прокрутку при нехватке высоты; в небольшом плеере проверить доступ ко всем шести кнопкам колесом мыши, жестами тачпада и полосой прокрутки без изменения позиции видео от прокрутки.
- [x] 3.6 Реализовать английские доступные названия, видимый фокус и стандартную клавиатурную активацию; проверить видимость сфокусированной кнопки, в том числе после прокрутки колонки.
- [ ] 3.7 Проверить безопасное отключение управления при неготовом VOD, рекламе и неопределённом контексте; подтвердить на реальном плеере, что расширение не перематывает неподходящее медиа.
- [x] 3.8 Добавить в английскую инструкцию описание наведения, направлений, прокрутки и поддерживаемых режимов; сверить со всеми реализованными состояниями.
- [x] 3.9 Скрывать колонки после 3 секунд без активности указателя, снова показывать при движении и сохранять видимость при клавиатурном фокусе; проверить таймер, повторное движение, уход указателя, отличие клика мышью от клавиатурного фокуса и очистку таймера при удалении управления автоматическими тестами.
